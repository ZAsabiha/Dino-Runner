# 🦖 Dino Runner (C++)

A fun twist on the classic **Chrome T-Rex Runner** game — but with **weapons, power-ups, and a shop system** 💥  
This project was built in C++ as a basic but exciting game development exercise. Some screenshots are attached at the end.

---

## 🎮 Overview

In this version of Dino Runner, the dino isn’t just running — it can **jump, duck, fire missiles,collect powerupps,shop**, and  using the score it earns. The game also **tracks the previous high score**, making each run more competitive.

---

## ✨ Features

- 🦖 **Jump and Duck** to dodge obstacles.  
- 💣 **Weapon System**  
  - Horizontal Missiles (`F`)  
  - Vertical Missiles (`V`)  
- 🛍️ **Shop System** — spend your score to buy weapons.  
- 🌟 **3 Types of Power-Ups** to enhance gameplay.  
- ❤️ **3 Lives** per run, adding more room for strategic play.  
- 📝 **High Score Tracking** between sessions.  
- ⏸️ Pause and resume the game anytime.

---

## 🕹️ Controls

| Key | Action                 |
|-----|--------------------------|
| `S` | Jump                     |
| `D` | Duck                     |
| `P` | Pause / Resume          |
| `F` | Fire Horizontal Missile |
| `V` | Fire Vertical Missile   |

---

## 🛒 Shop & Power-Ups

During the game, players can access the **shop** to buy weapons and power-ups using their in-game score.  
There are **3 types of power-ups**, each offering unique advantages (e.g., protection, extra firepower, etc.).

---

## 🧠 Project Motivation

This game started as a **basic recreation of the original T-Rex Runner**, but quickly became more fun as we added new features like weapons and shop mechanics.  
It was a great project to explore **C++ game loops, input handling, and state management** in a simple yet engaging way.
